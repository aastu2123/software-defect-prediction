
# Software Defect Prediction Using Machine Learning

## 1. Project Overview

This project investigates the use of machine-learning techniques
to predict whether software modules contain defects.

The objective is to develop a reproducible experimental workflow
for software defect prediction and evaluate model performance.

## 2. Research Questions

- How effectively can machine-learning models predict software defects?
- Which software metrics are useful for defect prediction?
- How do different models compare using appropriate evaluation metrics?

## 3. Repository Structure

- `data/`: Dataset sources and documentation.
- `notebooks/`: Exploration, preprocessing, and experiments.
- `results/`: Metrics, tables, and figures.
- `literature/`: Paper summaries and literature review.

## 4. Planned Workflow

1. Identify a suitable public dataset.
2. Review related research.
3. Explore and preprocess the data.
4. Establish a baseline model.
5. Train and compare machine-learning models.
6. Evaluate results and document limitations.

## 5. Reproducibility

Python dependencies are listed in `requirements.txt`.
Dataset sources, preprocessing decisions, and experiment
settings will be documented.
